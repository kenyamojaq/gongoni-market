# Gongoni Furniture Shop Website

This folder is ready for GitHub Pages.

## Upload To GitHub

1. Create a GitHub repository.
2. Upload everything inside this folder to the main/root of the repository.
3. Make sure `index.html` is in the root, not inside another folder.
4. In GitHub, open Settings > Pages.
5. Select Deploy from branch, choose `main`, then choose `/root`.
6. Save and wait for GitHub to publish the website link.

## Included

- Main shop page: `index.html`
- Product catalog and grouped photo slides
- 901 original product photos
- Compressed product thumbnails for fast catalogue browsing
- Product basket and checkout options
- Direct shareable links for every product
- Price-status, price-range, category, stock and sorting filters
- Mobile sticky shopping controls
- WhatsApp order button
- Direct Paybill details
- Malindi Town pickup and Kilifi County delivery fee options
- Customer sign up/sign in screen
- Admin edit page with stock, gallery grouping and on-device statistics: `admin.html`
